# Power Management Notes

Спосіб 1. Через Редактор локальної групової політики (для Windows Pro / Enterprise)

1. Натисніть комбінацію клавіш Win + R, введіть gpedit.msc і натисніть Enter.
2. У лівій панелі перейдіть за таким шляхом:
Конфігурація комп’ютера ➔ Адміністративні шаблони ➔ Система ➔ Керування живленням ➔ Настройки режиму сну
3. У правій частині вікна знайдіть два параметри:
	• Вимагати пароль, коли комп’ютер виходить із режиму сну (живлення від мережі)
	• Вимагати пароль, коли комп’ютер виходить із режиму сну (живлення від батареї)
4. Двічі клацніть на кожен із них, змініть значення на Не задано (Not Configured) або Вимкнено (Disabled).
5. Натисніть Застосувати та ОК.
6. Щоб політики оновилися негайно, відкрийте Командний рядок від імені адміністратора та виконайте команду:cmd
gpupdate /force
Будьте обачні, використовуючи код.

Для автоматичного блокування екрана через неактивність користувачі зазвичай використовують один із трьох класичних методів у Windows.


Метод 1. Перевірка «Граничного часу бездії комп'ютера» (Найімовірніше)

Ця політика повністю блокує зміну налаштувань у меню Windows і примусово закриває сесію.
• Через Групові політики (gpedit.msc):
	1. Натисніть Win + R, введіть gpedit.msc.
	2. Перейдіть: Конфігурація комп’ютера ➔ Конфігурація Windows ➔ Параметри безпеки ➔ Локальні політики ➔ Параметри безпеки.
	3. Праворуч знайдіть пункт: Інтерактивне підключення до системи: граничний час бездії комп’ютера (Interactive logon: Machine inactivity limit).
	4. Двічі клацніть на нього, видаліть цифру (там зазвичай стоять секунди, наприклад 300 або 900) та встановіть значення 0 або залиште порожнім, щоб вимкнути.
• Через Реєстр (regedit), якщо міняли там:
	1. Перейдіть до гілки:
HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows\CurrentVersion\Policies\System
	2. Знайдіть параметр InactivityTimeoutSecs.
	3. Клацніть правою кнопкою миші та видаліть його.


Метод 2. Перевірка застарілого блокування через Скринсейвер (Заставка)

Часто блокування налаштовують через примусове ввімкнення заставки з вимогою пароля.
• Через Групові політики (gpedit.msc):
	1. Перейдіть: Конфігурація користувача ➔ Адміністративні шаблони ➔ Панель керування ➔ Персоналізація.
	2. Перевірте параметри: Увімкнути заставку, Захист заставки паролем та Тайм-аут заставки.
	3. Переведіть усі ці три параметри у стан Не задано (Not Configured).
• Через Реєстр (regedit):
	1. Перейдіть до гілки:
HKEY_CURRENT_USER\Software\Policies\Microsoft\Windows\Control Panel\Desktop
	2. Видаліть параметри: ScreenSaveActive, ScreenSaverIsSecure, ScreenSaveTimeOut та SCRNSAVE.EXE, якщо вони там є


Метод 3. Затримка блокування екрана (DelayLockInterval)

Ви могли налаштувати примусовий інтервал для запиту пароля.
1. У редакторі реєстру (regedit) перейдіть за шляхом:
HKEY_CURRENT_USER\Control Panel\Desktop
2. Знайдіть параметр DelayLockInterval.
3. Клацніть по ньому правою кнопкою миші та видаліть.

🚀 Універсальний спосіб: Повне скидання всіх групових політик

Якщо ви не хочете шукати кожну гілку вручну, можна одним махом скинути всі локальні політики Windows до заводських налаштувань (це безпечно для системи, скинуться лише налаштування, які ви чи сторонні програми змінювали в gpedit.msc).
1. Відкрийте Командний рядок від імені адміністратора (у пошуку Windows введіть cmd, правий клік ➔ Запуск від імені адміністратора).
2. По черзі введіть і виконайте (натискаючи Enter) такі три команди:cmd
RD /S /Q "%WinDir%\System32\GroupPolicy"
Будьте обачні, використовуючи код.
